Section 3

Building a Classifier

You must compare J48 vs RandomTree on the credit-g.arff dataset.

Step-by-step:

  1. Open credit-g.arff in the Preprocess tab
  2. Go to the "Classify" tab
  3. Click "Choose" → navigate to trees → J48
  4. Click on the algorithm name to open its settings:
    • Set unpruned = False (pruned tree) → Click Start
    • Record: # Leaves, Correctly Classified %, Confusion Matrix
    • Then set unpruned = True → Click Start again
    • Record the same metrics
  5. Now click "Choose" → trees → RandomTree
  6. Run it and record the same metrics

📋 Fill in: Table 5 — Algorithm name, Pruned/unpruned, minNumObj, No. of Leaves, Correctly Classified Instances. Also analyze the confusion matrix each time.

Understanding the Confusion Matrix:

The confusion matrix shows actual vs predicted classes. Diagonal = correct predictions. Off-diagonal = errors. Look at: True Positives, False Positives, True Negatives, False Negatives.

Section 4

Using a Filter

Learn to use filters to modify data before classification. Three sub-tasks:

▶ 4a: Remove an attribute
  1. Open credit-g.arff in Preprocess
  2. Click "Choose" under Filter → filters → unsupervised → attribute → Remove
  3. Click on the filter name to configure it
  4. Set attributeIndices to the index of the attribute to remove (e.g., "1" to remove the first attribute)
  5. Click "Apply"

📝 Answer: "What are attributeIndices?" → They are the column numbers (1-indexed) of the attributes you want to remove. You can specify ranges like "1-3" or individual indices like "1,4,7".

▶ 4b: Remove instances where housing is "own"
  1. Open credit-g.arff in Preprocess
  2. Click "Choose" → filters → unsupervised → instance → RemoveWithValues
  3. Set attributeIndex to the index of the "housing" attribute
  4. Set nominalIndices to the index of "own" within that attribute's values
  5. Click "Apply"

📝 Answer: "What are nominalIndices?" → They are the indices of the specific values within a nominal attribute that you want to match for removal. E.g., if "housing" has values {rent, own, free}, and "own" is the 2nd value, then nominalIndices = "2".

▶ 4c: Fewer attributes, better classification?

Run J48 on credit-g.arff in three scenarios:

  1. Original — all attributes, run J48, record leaf size & accuracy
  2. Remove "checking_status" — remove attribute using the Remove filter, run J48 again
  3. Keep only "duration" and "credit_amount" — remove all other attributes (except class!), run J48

📋 Fill in: Table 6 — Filter applied, Leaf size, Correctly Classified %, and your Remark (does fewer attributes improve accuracy?).
